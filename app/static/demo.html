    What runs here
    
        
    The same payment code, Postgres transactions and Redis limits as the API. Payments go to Stripe in
          test mode when the server has a test key, and to a simulated gateway otherwise. Your browser gets its own
          demo session and never sees a merchant or administrator key.
    
      
    
      
    
        
    Why the replay matters
    
        
    If a response gets lost, the client sends the request again. Each operation carries a fixed request
          key, so the repeat returns the stored result and the card is charged once.
    
      
    
      
    
        
    Sessions
    
        
    A session lasts an hour. The free server sleeps after 15 idle minutes, and waking it ends every
          session, so you may need to start over.
